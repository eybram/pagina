# Documentación del proyecto

Este directorio concentra la documentación oficial de Broken Pocket y constituye la fuente principal de referencia para el desarrollo.

## Archivos principales

- [dev-plan/Architecture.md](dev-plan/Architecture.md): arquitectura técnica y responsabilidades por capa.
- [dev-plan/Project-requirements.md](dev-plan/Project-requirements.md): alcance funcional y objetivos del sistema.
- [dev-plan/Coding-guidelines.md](dev-plan/Coding-guidelines.md): reglas de implementación y convenciones.
- [dev-plan/Implementation-Plan.md](dev-plan/Implementation-Plan.md): orden de desarrollo y prioridades.
- [dev-plan/Decisions-Log.md](dev-plan/Decisions-Log.md): decisiones aprobadas que deben respetarse.
- [design-ref/Pallete-colors.md](design-ref/Pallete-colors.md): referencia visual y paleta de colores.

## Principios guía

- El proyecto sigue un enfoque Database First.
- SQL Server contiene la lógica principal del negocio.
- El backend actúa como capa de integración.
- El frontend es solo interfaz de usuario.
- Los cambios nuevos deben mantenerse alineados con los documentos de esta carpeta.
